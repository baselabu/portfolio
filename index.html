Bachelor's thesis

Simulation-Based Testing Framework for Embedded Systems Using MQTT and Cross-Compiled Code

ABB Bryne, Jan–May 2026. Team of three, supervised by Morten Mossige. Grade A.

  1. Virtual IPS controller
  2. Proxy (C#)
  3. MQTT broker
  4. RLC simulator (Python)

Testing control logic for ABB's IPS controller normally needs the physical hardware. We built a framework where a virtual IPS controller drives a simulated process instead, so the logic can be tested with no equipment on the desk.

A C# proxy reads analog outputs from the controller's shared memory and publishes setpoints over MQTT. A Python simulator models a second-order RLC circuit and sends the measurement back. We compared the simulator sample by sample against oscilloscope captures from the physical circuit.

My part: the proxy layer between shared memory and MQTT, and the latency measurements.
